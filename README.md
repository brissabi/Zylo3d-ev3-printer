# Zylo3D – EV3 Printer

Proyecto de impresora 3D experimental desarrollada con **LEGO Mindstorms EV3**, presentada en feria.

Zylo3D integra control mecánico, archivos de impresión 3D y documentación técnica, combinando robótica, fabricación digital y programación.

---

## 📂 Contenido del repositorio

- **Archivos 3D**: Modelos y piezas utilizadas en la impresora.
- **Archivos EV3** (`.ev3`, `.rtf`): Programas de control para el sistema EV3.
- **G-code** (`.gcode`): Archivos de impresión y calibración.
- **Scripts auxiliares**: Conversión y apoyo para manejo de archivos.
- **Documentación básica** del proyecto.
